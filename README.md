## Built-in objects and methods used

- `Date`: `new Date()`, `getMonth()`, `getDate()`, and `getFullYear()`.
- `String`: `String()`.
- `Number`: `Number()`, `Number.isNaN()`, `Number.isInteger()`, and `toFixed()`.

## Reflection
The easiest part was creating variables and performing the math calculations. The hardest part was formatting the results and displaying them correctly on the webpage. I learned that the Date object counts months starting at zero, so I needed to add one to get the correct month. I learned that Number() converts strings into numbers, while Number.isNaN() and Number.isInteger() check the converted values. I also learned how to use innerHTML to display results and += to add messages without replacing existing content.
